# Catalog — 27 Creative-Thinking Methods

Source: `megamouth/docs/creative-thinking-methodologies.md`. Grouping and wording match that catalog. ★ = one of the Suggested first 8.

## 1. Reframe the problem

| # | Slug | Method | ★ | When to call it / trigger phrases | Useful output |
|---|---|---|---|---|---|
| 1 | `lateral-thinking` | Lateral Thinking | ★ | "stuck," "samey ideas," dominant idea won't move, need indirect approach | Alternative frames, unexpected directions |
| 2 | `first-principles` | First-Principles Thinking |  | "this is how it is done" dominates | Constraint map, approaches free of convention |
| 3 | `challenge-assumptions` | Assumption Challenging | ★ | Overconstrained, every option looks impossible | Assumption inventory, alternatives, tests |
| 4 | `question-storming` | Question Storming |  | Vague brief, prematurely solution-focused, "are we solving the right problem?" | Better questions, revised problem statement |
| 5 | `abstraction-laddering` | Abstraction Laddering |  | Framing too narrow or too abstract | Connected goals, frames, concrete interventions |
| 6 | `inversion` | Inversion |  | Direct reasoning misses obstacles, "how would we guarantee failure?" | Failure conditions, design principles |

## 2. Generate more varied ideas

| # | Slug | Method | ★ | When to call it | Useful output |
|---|---|---|---|---|---|
| 7 | `scamper` | SCAMPER | ★ | Have a baseline concept/product/workflow to improve | 7-prompt variation set (S-C-A-M-P-E-R) |
| 8 | `reverse-brainstorming` | Reverse Brainstorming |  | Brainstorming stalled | Improvements derived from deliberately bad ideas |
| 9 | `forced-connections` | Random Stimulus / Forced Connections |  | Ideas too similar, need surprise | Surprising connections with value rationale |
| 10 | `analogical-thinking` | Analogical Thinking | ★ | Another domain may have solved this structurally | Analogies, transferable mechanism, limits |
| 11 | `morphological-analysis` | Morphological Analysis | ★ | Multiple independent design choices | Option matrix, promising combinations |
| 12 | `brainwriting` | Brainwriting |  | Early suggestions anchoring the group, need parallel divergence | Distinct idea batches + combinations |
| 13 | `crazy-eights` | Crazy 8s |  | Need 8 rapid alternatives before refining | Eight meaningfully different concepts |
| 14 | `constraint-driven-ideation` | Constraint-Driven Ideation |  | Open brief → generic ideas; want forcing functions | Concepts shaped by constraints, reusable insights |
| 15 | `ideal-final-result` | Ideal Final Result (TRIZ) |  | Incremental improvement feels insufficient | Ideal-state description + steps toward it |

## 3. Explore perspectives and possibilities

| # | Slug | Method | ★ | When to call it | Useful output |
|---|---|---|---|---|---|
| 16 | `six-thinking-hats` | Six Thinking Hats | ★ | Critique and ideation interrupt each other | Structured 6-mode exploration + synthesis |

| 18 | `stakeholder-perspectives` | Stakeholder Perspective-Taking |  | Solution helps one group, burdens another; overlooked voices | Tensions, unmet needs, better tradeoffs |

| 21 | `backcasting` | Backcasting |  | Long-term ambition lacks a credible route | Backward milestone sequence, near-term actions |
| 22 | `futures-wheel` | Futures Wheel |  | Idea may have broad ripple effects | 1st / 2nd / nth-order consequences map |

## 4. Turn exploration into stronger options

| # | Slug | Method | ★ | When to call it | Useful output |
|---|---|---|---|---|---|
| 23 | `double-diamond` | Double Diamond |  | Need both problem discovery and solution exploration | Problem definition, candidate directions, validation plan |

## Coverage map

- Methods overlap intentionally. Router prefers one primary + one alternate rather than forcing a single answer.
- If no installed skill matches the top pick, run the closest analogue and note the gap (e.g., `lateral-thinking` ≈ `divergent-thinking` + lenses).
- Agent/workflow candidates: `brainwriting` (parallel generation), `dreamer-realist-critic` (3-phase sequential), `six-thinking-hats` (6-mode + Blue synthesis), `scenario-planning`/`futures-wheel`/`morphological-analysis` (parallel then converge), `double-diamond` (orchestrator of other methods).
