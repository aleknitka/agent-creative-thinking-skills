## 1. Reframe the problem

| # | Slug | Method | ★/◆ | When to call it / trigger phrases | Useful output |
|---|---|---|---|---|---|
| 1 | `lateral-thinking` | Lateral Thinking | ★ | "stuck," "samey ideas," dominant idea won't move, need indirect approach | Alternative frames, unexpected directions |
| 2 | `first-principles` | First-Principles Thinking |  | "this is how it is done" dominates | Constraint map, approaches free of convention |
| 3 | `challenge-assumptions` | Assumption Challenging | ★ | Overconstrained, every option looks impossible | Assumption inventory, alternatives, tests |
| 4 | `question-storming` | Question Storming |  | Vague brief, prematurely solution-focused, "are we solving the right problem?" | Better questions, revised problem statement |
| 5 | `abstraction-laddering` | Abstraction Laddering |  | Framing too narrow or too abstract | Connected goals, frames, concrete interventions |
| 6 | `inversion` | Inversion |  | Direct reasoning misses obstacles, "how would we guarantee failure?" | Failure conditions, design principles |

| — | `c-k-theory` | C-K Theory | ◆ | Variation exhausted; need generative expansion, not selection | C-tree + K expansions + learning agenda |

## Coverage map

- Methods overlap intentionally. Router prefers one primary + one alternate rather than forcing a single answer.
- If no installed skill matches the top pick, run the closest analogue and note the gap (e.g., `lateral-thinking` ≈ `divergent-thinking` + lenses).
- Agent/workflow candidates: `brainwriting` (parallel generation), `dreamer-realist-critic` (3-phase sequential), `six-thinking-hats` (6-mode + Blue synthesis), `scenario-planning`/`futures-wheel`/`morphological-analysis` (parallel then converge), `double-diamond` (orchestrator of other methods).
- **Extended skills** reuse the same progressively-disclosed shape: `SKILL.md` (hub) + 5–7 leaf `references/*.md` + offline `scripts/*.py`; `thinking-router` scoring covers the base 27 + the 5 extended where installed.
- **Light touch-ups (no new skills):** `Dot Voting` and `15% Solutions` are documented in `options-portfolio` portfolio prioritization; `1-2-4-All` is noted in `brainwriting` facilitation; `Ecocycle Planning` is noted as a phase lens in `options-portfolio`. These are patterns, not separate skills.
