# When Not to Use Liberating Structures

- You need anonymous expert consensus over rounds → use nominal-group-technique (Delphi).
- You need ranked prioritization now → use dot-voting-prioritize.
- You need systematic invention inside a closed system → use systematic-inventive-thinking.
- Group <4 or purely individual work → use brainwriting or divergent-thinking.
- You need visual sensemaking of a mess before facilitation → use rich-picture-catwoe.
