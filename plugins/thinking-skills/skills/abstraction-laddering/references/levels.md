# Levels — Vision to Action

Each rung should be one level; mixing levels in a rung hides the missing middle.

- **Vision:** enduring aspiration (years) — no actor, no mechanism.
- **Purpose:** the outcome that matters in this horizon (months) — who benefits and how you would know.
- **Function:** what the system does, not how — a capability or service.
- **Mechanism:** the causal condition or process that produces the function — observable.
- **Action:** the concrete step taken now — owned, dated, testable.

Example chain: "users belong" (vision) → "new accounts reach first value in 7 days" (purpose) → "pre-configured entry" (function) → "invite carries intent, first open shows real work" (mechanism) → "one invite template that skips the tour" (action).
