# Worked Example — "Fix Signup" ↔ "Belonging"

## Start

Verbatim: "Fix the signup form." Goal behind it: more accounts complete signup. Too narrow — a patch.

## Ladder up

- Why does signup matter? → New accounts reach first value quickly.
- Why does first value matter? → Users feel competent and return.
- Why does that matter? → Teams adopt the product and retain.
- Stop: now at purpose that leaves the product's scope if pushed further.

## Ladder down from purpose

- How could "reach first value in 7 days" happen? → Pre-configured entry / checklist on real data / peer-propagated artifact.
- What would have to be true for pre-configured? → Invite carries intent; first open shows real work.

## Leverage

High-impact, high-control rung: "pre-configured entry" (function) — supported by one mechanism probe below (invite template) and one purpose check above (does faster first value actually predict retention?).
