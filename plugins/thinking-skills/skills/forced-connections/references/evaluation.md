# Evaluation — Novelty × Usefulness

Score each forced mapping on:

- **Novelty:** how distant from current design family (1–5).
- **Usefulness:** mechanism plausibility and goal fit (1–5).
- **Feasibility:** cost and time to probe (1–5).

Keep only those with plausible mechanism; discard novelty without usefulness. Kill criterion: if the mechanism requires the stimulus to be literally true, it is not transferable.
