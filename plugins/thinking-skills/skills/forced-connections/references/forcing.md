# Forcing — Property Mapping

## Steps

1. List 4–6 properties of the stimulus (not associations). Example: harbor → shelter, dock, pilot, channel, anchorage.
2. For each property, map onto the problem: if this property were true of our problem, what mechanism would it imply?
3. Complete the sentence: if [property] were true of [problem], then [mechanism] would follow.
4. Keep 2–3 strongest mappings with named mechanisms.

## Pitfalls

- Free-associating without listing properties — map, not vibe.
- Rewording the baseline as "inspired by" — without a mechanism it is not forced.
