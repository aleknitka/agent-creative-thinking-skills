# Worked Examples — 3 Forced Connections

## Problem
Onboarding drop-off.

## Stimulus: harbor
Properties: shelter, dock, pilot, channel → connection: onboarding as safe harbor where newcomers dock with a pilot (peer) and follow a clear channel (checklist on real data).

## Stimulus: volcano
Properties: pressure, eruption, dormancy → connection: onboarding pressure that erupts if unaddressed — instrument the pressure (activation dashboard) before eruption.

## Stimulus: mushroom
Properties: underground spread, pop-up where conditions are right → connection: peer-propagated entry — mushroom spreads via peers where work is already shared.
