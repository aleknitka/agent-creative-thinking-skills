# Forced Connections

Force an unrelated stimulus to matter. The distance between the stimulus and the problem is what breaks associative memory and produces surprise that still has a mechanism.

The failure mode it prevents is familiar associations reproducing the same category of answer with different labels.

## When to use

- Ideas cluster around one mechanism or category.
- The team keeps proposing variations of the same design family.
- You need deliberately distant inspiration before converging.

If unsure this is the right method, start with [thinking-router](../thinking-router/SKILL.md) — or see [references/when-not-to-use.md](references/when-not-to-use.md).

## When NOT to use (brief)

- You need mechanism transfer with stated limits → `analogical-thinking`.
- You have a concrete baseline to improve → `scamper`.
- Facts are missing → research first.

## Process

1. **Intake — reuse before you ask.** State the problem, goal, constraints, and what "too similar" looks like today. Mark fact / assumption / speculation. See [references/stimuli.md](references/stimuli.md).

2. **Choose stimulus type.** Pick random word, object, image, or concept — deliberately distant from the problem domain. Use a word bank or image set; avoid choosing something "relevant." See [references/stimuli.md](references/stimuli.md) and [scripts/connect.py](scripts/connect.py).

3. **Force the connection.** List 4–6 properties of the stimulus (not associations), then map each property onto the problem. For each, complete: if this property were true of our problem, what mechanism would it imply?

4. **Extract insight.** For the 2–3 strongest forced mappings, name the mechanism, the assumption challenged, and one enabling condition.

5. **Evaluate for value.** Score each on novelty × usefulness × feasibility; keep only those with a plausible mechanism.

6. **Probe.** Turn the strongest connection into one small test: what you would try, what signal would confirm it, and what would falsify it. See [references/examples.md](references/examples.md).

## Rules

- Stimulus must be unrelated — distance is the point; do not pick something "inspirational" that is actually near.
- Properties before connections — list properties of the stimulus before mapping; do not free-associate.
- Keep the mechanism visible — a vague "inspired by" without a mechanism is not a connection.
- Label fact / assumption / speculation.
- Honest provenance: call adaptations adaptations. See [references/provenance.md](references/provenance.md).
