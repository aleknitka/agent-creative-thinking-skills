# Crazy Eights

Eight ideas in eight minutes. Speed blocks self-censorship and the variety check forces distinct mechanisms, not eight wordings of the same design.

This is a text adaptation of the visual sprint format — eight brief concepts, each with a mechanism, not eight drawings.

The failure mode it prevents is premature refinement of one idea while cheaper, adjacent alternatives stay unexplored.

## When to use

- You need a quick burst of alternatives before you have time to deliberate.
- One idea is dominating and you need to break its hold.
- You want breadth quickly, then convergence.

If unsure this is the right method, start with [thinking-router](../thinking-router/SKILL.md) — or see [references/when-not-to-use.md](references/when-not-to-use.md).

## When NOT to use (brief)

- You need systematic coverage of a combinatorial space → `morphological-analysis`.
- You need many ideas with building on others → `brainwriting` or `divergent-thinking`.
- Facts are missing → research first.

## Process

1. **Intake — reuse before you ask.** State the problem, goal, hard constraints, and time available. Mark fact / assumption / speculation. See [references/procedure.md](references/procedure.md).

2. **Set up 8 slots.** Prepare eight positions — paper grid, doc table, or the template in [scripts/eights.py](scripts/eights.py). Each slot holds one brief concept.

3. **Generate 8 in 8 minutes.** One concept per minute, no discussion, no judgment. Each concept is a distinct mechanism or structure, not a rephrasing. Time-box visibly. See [references/procedure.md](references/procedure.md) and [scripts/eights.py](scripts/eights.py).

4. **Share and note variety.** Read aloud; mark which slots are distinct mechanisms and which are rewordings. See [references/variety.md](references/variety.md).

5. **Cluster.** Group the 8 by theme or mechanism; expect 3–4 clusters.

6. **Harvest.** Select the top 2–3 clusters as concepts with one probe each. Distinct means different mechanism, not different label. See [references/examples.md](references/examples.md).

## Rules

- One minute per slot — speed is the mechanism; do not deliberate.
- Distinct mechanisms only — rewordings do not count as new slots.
- No judgment during generation — cluster and evaluate after.
- Time-box visibly; facilitator does not contribute during generation.
- Label fact / assumption / speculation after harvest.
- Honest provenance: call adaptations adaptations. See [references/provenance.md](references/provenance.md).
