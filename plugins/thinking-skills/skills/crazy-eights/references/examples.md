# Worked Example — 8 Onboarding Variants

1. Pre-configured invite skips tour.
2. Checklist on real data inside first task.
3. Peer artifact as entry.
4. Import template pre-fills intent.
5. Time-box tour (2 min, then vanishes).
6. Chat concierge in week one.
7. Adaptive dashboard shows only 3 relevant services.
8. No interface — orientation outside product.

Cluster: pre-configured (1,4), learn-by-doing (2,5), social (3,6,7). Harvest top 2 clusters.
