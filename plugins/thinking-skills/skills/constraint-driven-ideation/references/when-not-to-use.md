# When NOT to Use Constraint-Driven Ideation — and What to Use Instead

## Quick triage

- Concrete baseline to improve → scamper
- Need many ideas without forcing → divergent-thinking or brainwriting
- Need ripple effects of one change → futures-wheel
- Need to choose among many → options-portfolio
- Near commitment and need to harden → premortem
- Facts are missing → research first

When unsure, triage with thinking-router.

Handoffs: generic brief narrowed → scamper; forcing reveals hidden assumption → challenge-assumptions; transferable insight needs systematizing → morphological-analysis.
