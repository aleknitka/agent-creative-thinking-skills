# Sequences — Which Order for Which Goal

Blue chooses the sequence at the open and may resequence mid-session. There is no single "correct" order — choose for the goal and time available.

## Quick picker

| Goal | Suggested sequence | Total time | When it fits |
|---|---|---|---|
| **Quick gut check** | Blue → White → Red → Blue | 5–8 min | Early reaction before data exists |
| **Quick decision tension** | Blue → Yellow → Black → Blue | 8–12 min | You already know the facts; need deliberate optimism and caution side by side |
| **Idea generation** | Blue → White → Green → Blue | 10–15 min | Problem is clear; you need alternatives fast |
| **Exploratory** (discover) | Blue → White → Red → Green → Blue | 15–20 min | Topic is open; map facts, feelings, and possibilities |
| **Full evaluation** (choose) | Blue → White → Red → Yellow → Black → Green → Blue | 25–35 min | Real decision with tradeoffs and a need for new options after critique |
| **Pre-mortem style** | Blue → White → Black → Green → Yellow → Blue | 20–25 min | Stress-test a plan before committing; Green repairs what Black finds |
| **Retrospective** | Blue → White → Red → Black → Yellow → Green → Blue | 25–30 min | Look back honestly, then extract what to keep and what to change |

## How to choose

1. Start from the **outcome** you need: reaction → map → generate → evaluate → decide → repair.
2. If you have **facts**, include White early; if you have **feelings to surface**, include Red before Yellow/Black.
3. Always place **Yellow before Black** — deliberate value before deliberate caution prevents premature dismissal.
4. Put **Green after Black** when you want creativity that repairs the weaknesses just named.
5. End every sequence with **Blue synthesis** — summary per hat, tensions, and next step.

## Adapting mid-session

- "We've run Yellow/Black and found the tradeoff is real — let's add a Green pass before we close."
- "We're mixing modes — Blue request: one hat at a time from now."
- "Time is short — Blue cuts to White → Yellow → Black → Blue and schedules Green separately."

## Pairing with other methods

- Green can delegate to `lateral-thinking` (provocations + movement) or `forced-connections` without leaving the hat structure.
- After a full sequence, `premortem` is a strong Black-hat deepening; `options-portfolio` is a Blue synthesis companion.
- For triage across methods, the router's triage (*better question / more ideas / broader perspectives / stronger options*) maps to sequence choice — exploratory vs. evaluation sequences correspond directly.

## Timing defaults (adjust explicitly via Blue)

- White: 4–6 min | Red: 1–2 min | Yellow: 4–5 min | Black: 4–5 min | Green: 6–10 min | Blue open/close: 2–3 min each.
- If a hat runs long, Blue names the new box ("extend White by 3 min") rather than letting it drift.
