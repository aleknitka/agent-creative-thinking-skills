# When NOT to Use Six Thinking Hats — and What to Use Instead

Six Thinking Hats structures **parallel thinking across modes**. If your bottleneck is not mode-mixing, another method fits better.

## Quick triage

| Your situation | Better fit | Why |
|---|---|---|
| You need stepwise correctness — proof, optimization, compliance, safety-critical sequence | **Vertical / critical thinking** | Rigor, not mode-separation, is the constraint |
| You don't know the facts yet | **Research first**, then return with White | Hats can't invent data |
| You need structured variations on an existing baseline concept | `scamper` | Narrower and systematic; hats too broad |
| You need to break a dominant frame sideways | `lateral-thinking` | Discontinuity via provocations; hats contain that as Green only |
| You need many options quickly without judging | `divergent-thinking` (10+ ideas + lenses → cluster → converge) | Quantity-first divergence; hats add process overhead |
| A recurring technical tradeoff blocks progress ("fix A, break B") | `triz-contradictions` | Contradiction-separation, not mode-separation |
| You need to choose or harden candidates | `premortem`, `options-portfolio` | Convergence and stress-testing, not parallel exploration |
| You want a quick single-mode pass | Run **one hat only** (e.g., Black on a launch plan) and name what was skipped | Full sequence is overkill under 5 min |

## Don't confuse

- **Hats are not personality types** — every participant uses every hat when it is called. Assigning "you are the Black hat person" misses the point.
- **Green is not the whole method** — Green **is** lateral thinking, but the hats add five other modes. If you only need Green, run `lateral-thinking` directly.
- **Yellow vs. Black** is not optimism vs. pessimism as mood — both are deliberate, reasoned modes with conditions and checks.

## Handoff triggers

When hats aren't the right entry point, triage with `thinking-router` (*better question / more ideas / broader perspectives / stronger options*).

Hats hand off to:

| Next | Trigger |
|---|---|
| `lateral-thinking` | Green is stuck — need provocations and movement |
| `challenge-assumptions` | White gaps reveal hidden "musts" to inventory |
| `scamper` | One Green alternative deserves systematic variation |
| `analogical-thinking` | A Yellow benefit hints at another domain's mechanism |
| `premortem` | Black needs deepening before commitment |
| `options-portfolio` | Blue synthesis has too many candidates to carry forward as-is |

## Anti-patterns

- Letting hats bleed — Yellow laced with Black, White laced with interpretation.
- Performing Blue as content — Blue manages *how*, not *what*.
- Using Red as a proxy for user research — label Red as subjective, hypotheses to validate.
- Skipping Blue close — ending without naming tensions and one next step.

## Discovery checkpoint (O5 review)

A brief critique pass that tests whether the hats fulfilled their intent: did each hat produce its own artifact before synthesis, and does Blue's close name the real tension with a testable next step? Keep it to 2–3 sentences; not a full rewrite.
