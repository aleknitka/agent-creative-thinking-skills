# Facilitation — NGT Discipline

- Question is one sentence, testable ("Which 5 onboarding fixes most reduce week-1 churn?"), not open editorial.
- Scribe records verbatim; no paraphrase. Number every idea.
- No cross-talk during round-robin; clarification questions allowed, advocacy forbidden.
- Timebox each phase visibly. Vote is independent — no caucusing, no show-of-hands dominance.
- Agent mode: one agent per voter for silent-write simulation; host clusters and tallies — do not auto-revoter after tally.
