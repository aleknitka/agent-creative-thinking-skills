# Worked Examples — Three What-If Worlds (Same Problem)

Problem: onboarding takes too long; users drop off before first success. Real goal: reach first meaningful outcome quickly.

## World 1 — Resource: attention is abundant

- Mutated assumption: attention is no longer scarce — users have unlimited willingness to read and watch.
- World sketch: onboarding could be a detailed 20-minute walkthrough; every feature is explained; no time pressure. Immediate consequence: drop-off disappears but feature recall stays low because passive viewing is weak learning. Adaptation: add practice prompts to keep attention active. Transferable insight: willingness alone doesn't teach — doing does. Principle: guided doing beats passive consumption where retention matters; holds while the task requires judgment, not just awareness. Probe: embed one task-based checklist vs. a video walkthrough; compare retention.

## World 2 — Interface: the screen disappears

- Mutated assumption: there is no onboarding interface — the user never sees a tutorial overlay.
- World sketch: users arrive pre-configured via invite or import; first open shows their real work. Immediate consequence: no tutorial to drop off from. Adaptation: orientation shifts to the invite or a peer artifact. Transferable insight: pre-configuration moves orientation outside the product, where context already exists. Boundary: holds where intent is known before entry (invite/import/team referral). Probe: one invite template that opens on real work, skipping the tour.

## World 3 — Actor: the user is someone else

- Mutated assumption: the user is not a solo individual but a pair (newcomer + nearby teammate).
- World sketch: the teammate's shared artifact is the entry point; orientation is peer-propagated. Immediate consequence: onboarding becomes social rather than instructional. Adaptation: design shareable artifacts that double as orientation. Transferable insight: peer proximity can carry orientation that instruction cannot, especially when real work is already shared. Probe: one shareable artifact that doubles as orientation; track adoption and time-to-first-value.
