# Worked Example — Onboarding Activation (Five Virtual Products)

Intake: onboarding flow as installed — invite, welcome email, product tour, activation check. Closed world: invite + welcome email + product tour UI + activation database + teammate's shared artifact. No new channel may be invented.

## Subtraction — remove the welcome email

Virtual product: no welcome email, ever. Gap: new users arrive without context, drop-off risks rising.

Enrichment: invite carries intent (team name, first task) so first open shows real work, not a generic tour. Benefit: fewer touchpoints, context at arrival. Qualitative change: orientation moves outside the product.

## Multiplication — copy the checklist with a changed condition

Virtual product: two checklists — one before first value (invite-carried) and one after, owned by the success team. Gap: who maintains the second list?

Enrichment: second checklist is generated from the first success event, not authored. Benefit: second list is always current. Probe: one success-team template seeded from real data.

## Division — split the flow

Virtual product: onboarding split into invite-time setup (before first open) and in-product verification (after). Gap: where does the handoff live?

Enrichment: handoff is the shared artifact itself; teammate ownership is visible at first open.

## Task Unification — give a new job to an existing element

Virtual product: the invite does the work of the welcome email. Gap: invite must be richer.

Enrichment: invite template includes first-task context; welcome email has no remaining job and is removed.

## Attribute Dependency — invite source controls tour presence

Virtual product: tour presence depends on invite source — invited users see no tour, solo users see the checklist. Gap: rule must be testable.

Enrichment: dependency stated as "if invited, suppress tour; else show checklist on real data." Benefit: differentiated experience without a new component. Probe: A/B by invite source.

## Shortlist

Keep Subtraction (invite as carrier) and Attribute Dependency (conditional tour). Both preserve the closed world and show a qualitative change; Multiplication and Division here converge on similar mechanics and would be merged.
