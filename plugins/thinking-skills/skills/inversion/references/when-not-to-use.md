# When NOT to Use Inversion — and What to Use Instead

## Quick triage

| Your situation | Better fit | Why |
|---|---|---|
| Concrete proposal near commitment | `premortem` | Declare one failure scene, generate independent reasons |
| Need many alternatives, not failure routes | `divergent-thinking`, `what-if` | Generation, not inversion |
| Need quantified hazard analysis | FMEA / HAZOP / fault tree | Auditable, not heuristic |
| Need evidence about one belief | Experiment / pilot / base rates | Test directly |
| Plan is locked | Track risks, postmortem | Cannot change |

## Don't confuse

- Inversion is general failure-route mapping; premortem is one declared failure with independent reasons.
- Inversion vs. reverse-brainstorming: reverse-brainstorming makes the problem worse then flips ideas; inversion extracts preventive principles.
