# Worked Example — Guaranteeing Onboarding Failure → Preventive Principles

Goal: new accounts reach first value in 7 days.

## Guaranteed failure routes (sample)

- Never name an owner for activation — drop-off is never reviewed.
- Front-load a tutorial that delays first value.
- Let invite intent disappear between signup and first open.
- Keep activation uninstrumented.
- Make sharing an artifact optional and unmeasured.

## Principles (negated, positive, testable)

1. Name an owner for each activation step and review drop-off weekly.
2. Deliver first value before instruction — checklist on real data.
3. Carry intent from invite to first open.
4. Instrument activation before you ship.
5. Make artifact sharing the default entry, not an option.
