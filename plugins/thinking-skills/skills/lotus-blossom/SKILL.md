# Lotus Blossom

Unfold radial abundance while the centre holds. Unlike linear 8, lotus keeps every new idea anchored to one of eight themes that themselves anchor to the original question — breadth with lineage.

The failure mode it prevents is explosive divergence that loses the question after the first ring, or a morph box tried before the space is understood.

## When to use

- 8 ideas would leave the space under-explored — you need 30–70 candidates to find surprising ones.
- You want hierarchical divergence (theme → petals → blooms) rather than flat lists or combinatorial matrices.
- Early problem space exploration — before morph box or SIT.

If unsure this is the right method, start with [thinking-router](../thinking-router/SKILL.md) — or see [references/when-not-to-use.md](references/when-not-to-use.md).

## When NOT to use (brief)

- You need convergence/prioritization now → `dot-voting-prioritize` or `nominal-group-technique`.
- The space is dimensions × options → `morphological-analysis`.
- Only 8 quick concepts needed → `crazy-eights`.

## Process

1. **Intake — name the centre theme.** Write the central question in one sentence (one verb + one constraint). Example: "Reduce week-1 activation drop without more email." List what is out of scope. See [references/procedure.md](references/procedure.md).

2. **Bloom the first ring — 8 petals.** Surround the centre with 8 distinct themes — each a different mechanism/lens, not a rewording. Check petals against variety: intent, timing, channel, actor, incentive, medium, trigger, failure mode. See [references/procedure.md](references/procedure.md).

3. **Bloom each petal — 8 per petal.** Treat each petal as a new centre; generate 8 children that still answer the petal's theme. Aim for 64 blooms (any 6 on a petal is enough if distinct). No judging during blooming. See [references/procedure.md](references/procedure.md) and [scripts/lotus.py](scripts/lotus.py).

4. **Prune for vitality.** Remove blooms that are restatements, infeasible without a new resource type, or orphaned from their petal's mechanism. Tag lineage: centre → petal → bloom. See [references/facilitation.md](references/facilitation.md).

5. **Harvest 3–5 probes.** Choose surprising-but-testable blooms from different petals; for each define the smallest probe, signal, and owner. Handoff to `premortem` before commitment or back to next petal if a theme deserves its own lotus. See [references/examples.md](references/examples.md).

## Rules

- One theme per centre — do not change the centre while blooming.
- Petals must be distinct mechanisms, not synonyms — variety check before second-ring bloom.
- One idea per bloom cell; keep lineage (P3-B7) so provenance is traceable.
- No evaluation during blooming — pruning only after 72 are attempted.
- Quantity then vitality — fill first, judge second.
- Label fact / assumption / speculation; centre is the question, blooms are hypotheses.
- Honest provenance: attribute Lotus Blossom to Yasuo Matsumura; call this workflow an adaptation. See [references/provenance.md](references/provenance.md).
