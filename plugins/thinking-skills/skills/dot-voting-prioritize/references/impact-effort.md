# Impact–Effort Matrix

```
        Low effort    High effort
High I  Quick wins    Strategic bets
Low I   Fill-ins      Avoid / kill
```

- Impact 1–5: value if it succeeds (revenue, time saved, learning).
- Effort 1–5: cost to attempt (person-days, dependencies, risk); 5 = hardest.
- Plot quickly — 30 seconds per item. Disagree → note as dissent, do not debate until plot is complete.
