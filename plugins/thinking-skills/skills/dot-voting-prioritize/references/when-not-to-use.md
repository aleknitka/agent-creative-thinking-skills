# When NOT to Use Dot Voting + Impact–Effort/ICE

## Use a different method

- **Ranking by expert judgment with anonymity and controlled feedback** →
  `nominal-group-technique`. Dot voting is visible and social; it cannot remove conformity
  pressure among experts.
- **Keeping a mix of safe, ambitious, and exploratory bets** →
  `options-portfolio`. A dot vote tends to collapse to one or two winners;
  portfolio thinking deliberately keeps variety.
- **Hardening one proposal before commitment** → `premortem`.
- **Generating or broadening options** → `divergent-thinking`,
  `brainwriting`, `scamper`, or `question-storming` first.
- **The item set is unclustered** → cluster during divergence. Voting on 100
  raw notes measures reading stamina, not preference.
- **A hard constraint or safety issue decides the answer** → a governance or
  risk process. A vote that cannot change the outcome wastes trust.
- **Irreversible, capital-scale decisions** → decision memo plus `premortem`;
  ICE is built for cheap reversible experiments.
- **A single owner's backlog with obvious severity order** → a simple
  criteria table or existing priority scheme is cheaper and less ceremonial.
- **The group is too small or too conflicted for a fair ballot** (e.g. two
  factions, one decider) → facilitated decision with explicit rationale.

## Triage questions

1. Is the set clustered, comparable, and visible? If not, fix that first.
2. Is the decision reversible and within existing authority? If not, use a
   governance path.
3. Would anonymity change the answer? If yes, use `nominal-group-technique`.
4. Does the decision need a *mix* rather than a ranking? If yes, use
   `options-portfolio`.
5. Is there evidence to score Confidence? If not, keep ICE optional and say
   the ranking is judgment.

## Handoff map

| Situation | Next method |
|---|---|
| Too many raw ideas | cluster, then return here |
| Need anonymous expert ranking | `nominal-group-technique` |
| Need a balanced set of bets | `options-portfolio` |
| One proposal needs stress-testing | `premortem` |
| Top item needs a causal test | experiment design / probe |
| Item is under-specified | back to divergence |
| Stakeholders disagree on values, not facts | decision owner + recorded rationale |

When unsure, triage with [thinking-router](../../thinking-router/SKILL.md).
