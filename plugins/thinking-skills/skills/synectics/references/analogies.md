# The Four Synectics Analogies

## 1. Personal analogy — be the element

Speak as the element: "I am the invite — I feel rushed, then discarded." Embodiment surfaces constraints that description hides.

Prompt: "If you were the onboarding email, what would you want and fear?"

## 2. Direct analogy — parallel mechanism in another domain

Find a mechanism that solves a structurally similar problem elsewhere. Name the domain and the mechanism, not just the similarity.

Prompt: "Where else does a stranger become a member without a formal gate? How does that system handle it?"

## 3. Symbolic analogy — compressed paradox

Compress the problem into a two-word paradox that holds a tension. Examples: "trusted stranger," "guided abandonment," "silent signal." The image must carry contradiction, not harmony.

Prompt: "State the core tension as a paradox — two words that should not go together but do here."

## 4. Fantasy analogy — wishful, constraint-free

Remove constraints entirely: "If physics and policy vanished, how would this work?" Record the wish without censoring for feasibility.

Prompt: "If nothing were forbidden, how would activation happen?"

## Running the set

Build all four in order; each estranges differently. Mark which analogy felt most evocative — it will lead the excursion.

## Quality check

Each analogy must name a structure, feeling, or mechanism — not just a label. A direct analogy without a mechanism is not an analogy in Synectics.
