# Portfolio — Achievable / Ambitious / Exploratory

- **Achievable:** ships soon with known resources.
- **Ambitious:** high upside if it works, higher cost to attempt.
- **Exploratory:** high learning even if it fails; tests a load-bearing belief.

Compose so each is present where possible; no two should be the same mechanism.

## Prioritizing with Dot Voting and Ecocycle

- **Dot Voting:** distribute 3-5 dots per person across portfolio candidates; tally as one signal, not the decision. Use after clustering, before the final 3-5 selection.
- **Ecocycle Planning:** map candidates onto Birth -> Maturity -> Creative Destruction -> Renewal to see which phase each portfolio item serves; helps avoid a mature-only portfolio.
- **15% Solutions:** if one portfolio item must move today, extract the 15% Solution — what can be done without extra resources or approval — as its immediate probe.
