# Decomposition — Stripping to Fundamentals

## Why-why without infinite regress

Ask "why must this be so?" until the answer is one of: physics, regulation, invariant, or directly observed fact. Stop when the next why would require a different problem to answer, or when the chain repeats a prior answer.

Prompt set:

- What is this in service of — the goal or the means?
- Who decided this, when, on what evidence?
- What would break if this were removed tomorrow?
- What does one team or competitor do that violates this and survives?

## Classification test

For each row: if a single counterexample exists (one team operating without it), it is inherited. If the violating case would break physics, law, or a named invariant, it is fundamental. Otherwise, name the preference owner.

## Stripped statement

After classification, write the minimal problem: "Achieve [goal] for [whom] under [fundamentals + observed facts] without assuming [inherited constraints set aside]." Keep the set-aside list visible — you will consider adding items back during rebuild.
