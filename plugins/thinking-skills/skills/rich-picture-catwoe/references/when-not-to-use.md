# When NOT to Use Rich Picture + CATWOE — and What to Use Instead

## Quick triage

| Your situation | Better fit | Why |
|---|---|---|
| A clear, agreed problem statement already exists | Validate it or probe directly | Redrawing disperses consensus |
| You need causal feedback analysis | `causal-loop-diagram` | CATWOE is definitional; CLD is causal |
| The block is a recurring technical contradiction | `triz-contradictions` | Tradeoff analysis, not situation picture |
| You need stakeholder tradeoffs broadly | `stakeholder-perspectives` | Social mapping without a root definition |
| Near commitment and need to harden | `premortem` | CATWOE debates before modeling, not after commitment |
| You have a well-scoped baseline to vary | `scamper`, `morphological-analysis` | Systematic variation, not situation definition |

## Don't confuse

- **Rich Picture vs. Futures Wheel / Scenario Planning:** the rich picture is present-state sensemaking; futures methods explore consequences or plausible futures. Draw the now before imagining the later.
- **CATWOE vs. Challenge Assumptions:** both surface worldviews, but CATWOE produces a testable root definition (W + T + C/A/O/E). Use CATWOE when the definition itself is contested.

## Handoff triggers

When Rich Picture + CATWOE isn't the right entry point, triage with `thinking-router` (*broader perspectives / better question*).

Rich Picture + CATWOE hands off to:

| Next | Trigger |
|---|---|
| `causal-loop-diagram` | Picture reveals a reinforcing loop to formalize |
| `stakeholder-perspectives` | CATWOE debate surfaced a marginalized worldview |
| `premortem` | You selected a root definition and need to harden |

## Anti-patterns

- Drawing a process map and calling it a rich picture — actors and worldview hints are required.
- CATWOE without a stated W — the design bet stays hidden.
- One CATWOE that blends multiple transformations.
