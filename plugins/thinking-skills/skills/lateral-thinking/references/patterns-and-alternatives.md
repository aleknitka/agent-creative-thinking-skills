# Patterns & Alternatives — Fractionation, Concept Fan, Disproving

Three de Bono tools that widen the space before you harvest. Use them when brainstorming has clustered or when movement from Pos has stalled. Each is a half-page technique, not a separate skill.

## 1. Fractionation — break the fixed view into parts

**When:** The situation feels like one solid block.

**How:**
1. List the elements you see as a single whole (steps, actors, channels, time, cost).
2. Break the whole into 3–5 parts and reframe each part separately: "What if this part were the whole problem?"
3. Generate one alternative per part, then look for a synthesis across parts.

**Example:** "Onboarding" → fractionate into *invite → first open → first success → habit*. Provoke each: `Po, invite does all the work` vs. `Po, first success happens outside the product`.

**Attribution:** de Bono, *Lateral Thinking* (1970); also called "fractionation of the situation."

## 2. Concept Fan — broaden the concept level, then re-narrow

**When:** Ideas cluster at one level of abstraction ("we need a better tutorial").

**How:**
1. Write the current concept (e.g., "tutorial").
2. Move **up** one level: what is the broader concept? ("help users reach first success").
3. Move up again if useful ("help users feel competent").
4. Then **fan out** at that higher level: list 3–4 alternative concepts that also serve it (pre-configuration, peer help, doing, deferral).
5. Pick one concept and generate concrete implementations.

```
tutorial  →  help users reach first success  →  help users feel competent
                                              ↘ pre-configure
                                              ↘ peer-guided
                                              ↘ learn by doing
                                              ↘ defer learning entirely
```

**Attribution:** de Bono, *Serious Creativity* (1992) — concept fan.

## 3. Disproving — argue the opposite of the taken-for-granted

**When:** Something "goes without saying."

**How:**
1. State the taken-for-granted belief explicitly.
2. Take the opposite view and argue it convincingly (borrow de Bono's note that "the majority is always wrong" is a deliberate stance, not a claim about truth — cf. Ibsen/Galbraith references in *Lateral Thinking*).
3. Note what would have to be true for the opposite to hold; that condition may be your next frame.

**Example:** Taken for granted: "Onboarding must teach the product." Opposite: "Onboarding must hide the product." Argue it: hiding reduces choice, preserves momentum, lets real work teach.

**Caution:** This is a thinking mode, not a personality trait — similar overlap with Six Thinking Hats Black Hat caution.
