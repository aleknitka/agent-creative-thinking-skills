# Concept Blending

Combine mechanisms, not features. Two partial ideas each carry something worth keeping — this skill blends them into one coherent concept with a stated rationale, not a feature pile.

The failure mode it prevents is picking one half-idea while discarding the other half's mechanism, or accumulating both without integration.

## When to use

- Several partial ideas each carry a mechanism worth keeping.
- Choosing among them would discard value; accumulating them would create a pile.
- You need synthesized concepts with a clear rationale for the blend.

If unsure this is the right method, start with [thinking-router](../thinking-router/SKILL.md) — or see [references/when-not-to-use.md](references/when-not-to-use.md).

## When NOT to use (brief)

- One clear best idea exists → refine it.
- You need breadth before synthesis → `divergent-thinking`.
- Candidates must be hardened, not blended → `premortem`.

## Process

1. **Intake — reuse before you ask.** State the goal, the 2–4 partial ideas, what each does well, and hard limits. Mark fact / assumption / speculation. See [references/blending.md](references/blending.md).

2. **Name mechanisms.** For each partial, extract its mechanism — the causal operation that produces its value — distinct from its surface feature. See [references/blending.md](references/blending.md) and [scripts/blend.py](scripts/blend.py).

3. **Blend.** Combine mechanisms from distinct ideas into one coherent design. Keep the rationale for why the combination improves on either parent — compatibility, coverage, or tradeoff break — not just additive value. See [references/synthesis.md](references/synthesis.md).

4. **Test coherence.** Does the blend introduce a contradiction or duplicated cost? If yes, revise by separation (different space, time, or condition) rather than accumulation.

5. **Name tradeoffs.** State what the blend keeps, what it drops, and what new cost it adds. Compare against parents on the same benefit.

6. **Probe.** Define the smallest test of the blended mechanism and its signal. See [references/examples.md](references/examples.md).

## Rules

- Blend mechanisms, not features — accumulation is not synthesis.
- Every blend must state why the combination improves on either parent.
- No pile: if the blend keeps both parents fully, it is accumulation.
- Label fact / assumption / speculation.
- Honest provenance: call adaptations adaptations. See [references/provenance.md](references/provenance.md).
