# Idea Lenses

Apply a lens by asking its prompt about the current problem.

| Lens | Prompt |
|------|--------|
| Invert | What would make this problem worse? Now reverse each answer. |
| Constrain | What if it had to cost nothing / take one minute / use one tool? |
| Extreme | What if it had to serve 1,000x more users, or just one? |
| Borrow | How does biology, logistics, games, or cooking solve a similar problem? |
| Remove | What if the main component did not exist? |
| Combine | What two existing ideas could be merged? |
| Reframe | What if the real problem were something else entirely? |
| Persona | How would a child, an expert, or a skeptic approach this? |
