# Facilitation

Question storming fails in predictable ways: the first question anchors the
group, senior people's questions crowd out others, and someone answers instead
of asking. The mechanics below exist to prevent that.

## The four rules

1. **Questions only.** No answers, no explanations, no defending a question.
   If someone answers, convert it: "What evidence would support that?"
2. **Quantity before quality.** Set a target (20–40) and keep going past the
   point where the obvious questions run out. The useful reframes usually
   arrive after the first ten.
3. **Do not judge during generation.** No "that's out of scope," no "we
   already know that." Evaluation happens at clustering.
4. **Capture verbatim.** Write the question as asked. Paraphrasing during the
   storm silently deletes the framing you are trying to examine.

## Formats

### Solo (default for an AI agent)

Work in writing, moving through categories rather than free-associating.
Generate at least four questions per category before reviewing any of them.
Keep the brief visible and copy its exact nouns into questions — this prevents
drift into generic problem-solving.

A useful sequence:

1. Clarifying pass — one question per ambiguous noun or metric.
2. Reframing pass — why this, why now, what is above it.
3. Stakeholder pass — affected, deciding, paying, missing.
4. Constraint pass — fixed, imposed, assumed.
5. Causal pass — evidence, mechanism, counterfactual.
6. Generative pass — what if, how might we.

### Group, in person or on a call

- **Silent start (3–4 minutes).** Everyone writes questions independently
  before anyone speaks. This is the single highest-value mechanic; it prevents
  anchoring and gives quiet participants equal footing.
- **Round-robin.** Each person offers one question per turn, then passes.
  Passes are allowed; commentary is not. Continue for 2–3 rounds.
- **One question per turn.** No stacked questions with a preferred answer in
  the second clause.
- **Build, don't debate.** "A question that follows from that is …" is
  allowed. "That's already answered" is not.
- **Separate roles.** One facilitator enforces the rules; one scribe captures
  verbatim. The facilitator does not evaluate questions.

For a time-boxed burst, four minutes of pure question generation is enough to
surface material; longer sessions trade novelty for fatigue. Run a second
burst after clustering rather than extending the first.

### Async / written

Collect questions in a shared document with one section per category and no
attribution required. Attribute only when ownership of a question matters for
follow-up. Async storms benefit from a hard deadline and a stated target
count.

## Anti-patterns

| Symptom | Cause | Fix |
|---|---|---|
| Ten questions, all about implementation | The brief's framing was accepted | Run a reframing pass before continuing |
| Questions get longer and more rhetorical | Answers smuggled in as questions | Enforce interrogative grammar and one clause |
| Senior person's list dominates | Spoken brainstorming | Silent writing, then round-robin |
| The same question reworded | No capture discipline | Cluster only after generation; keep verbatim |
| Everyone stalls at question 12 | Judging begins | Restate the target; ask for bad questions deliberately |
| Storm ends with a solution | Evaluation crept in | Park all solutions; reopen generation |

## From storm to clusters

Only after generation:

1. Read the full list without commenting.
2. Merge exact duplicates; keep near-duplicates until you see whether the
   difference matters.
3. Group by **what the answer would change**, not by topic or department.
4. Name each cluster as a gap: "we do not know whether activation is limited
   by setup effort or by missing intent."
5. Separate questions that are already answerable from existing evidence, and
   questions that are assertions in disguise.
6. Hand the clusters to prioritization.

## Working with an AI agent

The agent should generate the storm itself, then expose it for correction.
Ask for categories explicitly, require verbatim capture, and forbid answers in
the generation pass. A second pass can challenge the storm: "which categories
are thin, and what question is missing?" Do not let the agent quietly collapse
the list into a recommendation before the human has seen the raw questions.
