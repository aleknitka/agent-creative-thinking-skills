# When NOT to Use Crazy Eights — and What to Use Instead

Crazy Eights is a breadth sprint for a defined problem. If the problem is undefined, the space needs systematic coverage, or the job is refinement rather than breadth, another method fits better.

## Quick triage

| Your situation | Better fit | Why |
|---|---|---|
| Need systematic coverage of combinations of independent choices | `morphological-analysis` | The box maps the space; Crazy Eights samples it by intuition and can miss whole regions |
| Need volume without a fixed count or clock | `brainwriting`, `divergent-thinking` | No artificial limit; better when quantity itself is the goal or the group is large |
| One baseline to improve incrementally | `scamper` | Seven prompts on an existing object produce targeted variations, not eight new concepts |
| The question itself is wrong or too narrow | `question-storming`, `lateral-thinking` | Reframe first; eight fast answers to the wrong question entrench it |
| Need to stress-test one chosen concept | `premortem` | Failure imagination, not breadth |
| Have a candidate set and must choose | `options-portfolio` | Selection and portfolio construction, not generation |
| Need to plan across several plausible futures | `scenario-planning` | External uncertainty, not internal alternatives |
| Missing facts about users, constraints, or feasibility | **Research first**, then return | Fast generation on unknown ground produces confident fiction |
| Need a decision now with clear criteria and a small option set | Plain decision analysis | The eight-slot ritual adds overhead and no coverage |

## Crazy Eights vs divergent thinking

Divergent thinking is the umbrella: defer judgment, aim for quantity, welcome wild ideas. Crazy Eights is a specific, timeboxed instance of it.

- Use **divergent-thinking** when the problem is still forming, when you want a long list, or when the session has no natural stopping rule.
- Use **Crazy Eights** when you want a small, comparable set quickly, and the comparison is the point — eight slots are easy to read, cluster, and vote on.
- Crazy Eights is not a substitute for a proper divergent phase on a new domain. If the team cannot name even three mechanisms, brainstorm broadly first, then run Crazy Eights on the refined prompt.

A practical chain: divergent pass → pick two or three promising directions → Crazy Eights on the sharpest one → cluster → probe.

## Crazy Eights vs morphological analysis

Morphological analysis decomposes a solution into independent dimensions and enumerates the options on each. Crazy Eights generates whole concepts, one per slot, with no explicit dimension model.

- Use **morphological-analysis** when the design space has visible independent choices and you need coverage or a defensible combination shortlist.
- Use **Crazy Eights** when the space is not yet decomposed and you need raw material to see what the dimensions might be.
- Crazy Eights has a known bias: eight concepts produced fast will over-sample familiar mechanisms. Morphology corrects for that with explicit dimensions and pruning.

A practical chain: Crazy Eights first to surface candidate mechanisms → morphological analysis on the two or three most different mechanisms → sample combinations → probe. Do not present eight fast concepts as a coverage argument; they are not.

## Other adjacent methods

- **Brainwriting** is silent parallel generation with rotation; it removes blocking and produces more ideas than eight, but takes longer and needs a group. Use it when social dynamics are the problem.
- **SCAMPER** starts from a baseline and applies seven operators. Use it when you have something to improve, not a blank page and a question.
- **Forced connections** and **concept blending** create novelty by joining unrelated material. Use them when Crazy Eights' eight slots are too polite and you need genuinely non-obvious mechanisms.
- **Ideal final result** works backwards from a perfect outcome. Use it when the constraint set is the problem and you need to suspend assumptions first.
- **Design sprint** uses Crazy Eights as one step inside a longer sequence. If you are running the full sprint, follow its facilitation rather than this skill's standalone adaptation.

## Overkill signals

Crazy Eights is the wrong tool when:

- The option set already exists and is small — you need a decision, not more options.
- The problem is a single technical contradiction with a known trade-off; enumerate around it after resolving it.
- The team cannot commit eight minutes of silence, or the facilitator will fill the silence with examples.
- The output would be judged as a recommendation. Eight concepts are material, not a shortlist; if nobody will cluster and probe, the exercise becomes theatre.
- The prompt is a slogan ("make it delightful"). Narrow it before spending slots.
- The work needs correctness, compliance, or a single defensible answer. Breadth can hide the fact that one constraint decides the issue.

## Handoff triggers

| Next | Trigger |
|---|---|
| `morphological-analysis` | The eight reveal recurring dimensions; map them explicitly before choosing |
| `scamper` | One concept is promising and needs systematic variation before piloting |
| `concept-blending` | Two slots from different clusters should be fused |
| `options-portfolio` | Eight concepts are too many to probe and need portfolio-level selection |
| `premortem` | A concept is chosen and needs failure analysis before commitment |
| `first-principles` | The eight keep collapsing into the same mechanism; the model of the problem is wrong |
| `question-storming` | Every slot answers a slightly different question; reframe the prompt |
| **Research** | Feasibility, user behaviour, or constraints are simply unknown |

## Anti-patterns

- **Eight costumes, one idea** — the same mechanism reworded across all slots.
- **The polite eight** — every concept feasible, incremental, and on-brand; this is a shortlist pretending to be a breadth pass.
- **Sketch theatre** — elaborate drawings that consume the minute and hide the absence of a mechanism.
- **Voting too early** — ranking during generation or immediately after sharing, before variety is understood.
- **Ignoring the outlier** — dropping the strange slot because it is hard to score; it often holds the only new information.
- **No probe** — the session ends with a gallery and no scheduled test. Nothing was learned.
- **Wrong clock** — stretching to 20 minutes for "quality", which restores elaboration and defeats the method.
