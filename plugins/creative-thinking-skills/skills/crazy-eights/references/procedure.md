# The 8-in-8 Procedure

Crazy Eights works because the constraint is absurd: eight ideas in eight minutes leaves no room for elaboration. That is the point. The clock converts "think of something good" into "put something in the slot and move".

## Before the clock starts

Settle these five things in five minutes or less:

1. **One prompt, phrased as a question.** "How might we make the first week of onboarding feel worth the effort?" beats "onboarding ideas". If the prompt contains two problems, split it or pick one.
2. **The audience and the moment.** Who is doing what, when the concept intervenes, and what they experience before and after.
3. **Success in one sentence.** What would count as better — activation, time saved, fewer support contacts, willingness to pay. Keep it loose; this is a compass, not a scoring rubric.
4. **Hard constraints.** Budget, law, brand, platform, deadline. Write them where they stay visible; they are the walls of the space, not the ideas.
5. **What has been tried.** Two or three failed or current approaches, so the eight do not all reproduce them.

If the prompt is still vague after this, stop. Eight fast concepts built on an undefined problem produce eight ways to be confused.

## Set up the slots

Physical version: fold a sheet into eight rectangles, number 1–8, one minute each.

Text version: create eight rows with the same fields. Keep them short enough to fill at speed:

| Slot | Time | Concept (1–2 sentences) | Mechanism (3–6 words) | Differs from | Assumption |
|---|---|---|---|---|---|
| 1 | 0:00–1:00 | | | | |
| 2 | 1:00–2:00 | | | | |
| … | | | | | |
| 8 | 7:00–8:00 | | | | |

Use the companion helper (scripts/eights.py) to generate this template with time boxes and variety seeds.

Rules for the template:

- One concept per row. No sub-bullets, no feature lists.
- The mechanism field is mandatory. If you cannot name one, the row is a slogan.
- "Differs from" names the nearest earlier slot and the axis of difference (actor, trigger, channel, form, incentive, constraint).
- "Assumption" gets one line — the belief that must hold for the concept to work. It is not a caveat; it is the thing to probe later.

## The eight minutes

A rhythm that survives contact with reality:

- **Minute 0–1:** write the first concept immediately. Do not choose the best first concept; choose the first one that is concrete enough to fill the row.
- **Minutes 1–7:** one slot per minute. At the top of each minute, read only the prompt and constraints — not the previous rows. Starting from the last idea is how eight slots become one idea in eight costumes.
- **When a slot stalls:** write the most obvious, boring version and move on. Or invert the previous slot: if it is a human touchpoint, make it automatic; if it is opt-in, make it default. The stall usually means you are trying to make the slot good.
- **Minute 7–8:** finish slot 8, even if it is rough. Rough is data: it shows which region of the space you cannot reach quickly.
- **At 8:00:** stop. If a ninth idea is forming, put it in a parking lot outside the eight. Do not replace a slot.

Strict 1-minute slots are the default. Use 2-minute slots only when the domain is genuinely complex and the group is new; then the exercise is "eight in sixteen", and you should say so rather than silently stretching "eight in eight".

## After the clock

Do not start evaluating inside the generation artifact. Copy the eight into a fresh sheet, read them in order, and only then name mechanisms and clusters. The order matters: reading 1–8 before discussing prevents the loudest idea from becoming the frame.

Freeze the set at eight. If the session later produces more ideas, that is a different exercise. The value of the eight is that they were produced under the same constraint and can be compared.

## Common failure modes

- **Slot inflation:** slots 1–2 get three sentences and the rest get fragments. Enforce equal size; detail is what refinement is for.
- **The polite eight:** all eight are feasible, incremental, and on-brand. You have produced a shortlist, not a breadth pass.
- **Time theft:** "just one more minute" on slot 5. The deadline is what forces the rough slots that reveal the edges.
- **Silent evaluation:** crossing out and rewriting during generation. Keep a parking lot for critiques and use it afterwards.
- **Prompt drift:** each slot answers a slightly different question. Re-read the prompt at every minute boundary.
