# Worked Example — 3 Constraints → 3 Transferable Insights

## Problem

Open brief: improve onboarding; current ideas converge on "guided tutorial inside product."

## Constraints and concepts

**No interface:** onboarding has no screen — pre-configured entry where invite or import carries intent; first open shows real work. Mechanism: configuration outside the product.

**One day:** ship a fix in one day — checklist on real data that completes onboarding as the first task is done. Mechanism: learn by doing, not before.

**Offline-only:** no product touch — peer artifact as entry and orientation; teammate shares work that doubles as guidance. Mechanism: social propagation.

## Transfer

- Pre-configured entry transfers even without the "no interface" constraint — invite already carries intent.
- Checklist on real data transfers as "instruction inside the task" even when time is not tight.
- Peer artifact transfers as the social path complements, not replaces, in-product help.

Probes: invite template that skips the tour, real-data checklist, shareable artifact — each with kill criterion.
