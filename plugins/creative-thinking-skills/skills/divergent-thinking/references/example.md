# Worked Example: Naming a CLI tool

**Problem:** name a tool that syncs dotfiles. **Goal:** memorable, typeable, not taken.

**Raw options (no judging):** dotsync, rootkit, homebase, stow2, nest, burrow, molt, tether, dotty, hearth, ...

**Lenses applied:**
- Borrow (animals that carry their home): burrow, hermit, snail, molt.
- Constrain (max 4 letters): nest, molt, dots, sync.

**Clusters:** literal (dotsync), shelter metaphors (nest, hearth, burrow), animal metaphors (molt, hermit). Unexplored: playful/abstract.

**Converge** on criteria (typeable, metaphor fits "portable home"): `nest`, `burrow`. Dropped `dotsync` as too generic.
