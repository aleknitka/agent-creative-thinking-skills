# Synectics + Excursion

Make the familiar strange, then the strange familiar. Synectics moves beyond one-off stimulus by running four disciplined analogy types and an excursion — a temporary departure into an apparently unrelated world — then forcing the journey back.

The failure mode it prevents is shallow analogy that borrows surface features without a mechanism, and stimulus that never leaves the problem's vocabulary.

## When to use

- Familiar analogies stall — every comparison lands in the same domain.
- Forced connections feel too shallow to carry a mechanism.
- You need a disciplined excursion beyond the problem, not a random word.

If unsure this is the right method, start with [thinking-router](../thinking-router/SKILL.md) — or see [references/when-not-to-use.md](references/when-not-to-use.md).

## When NOT to use (brief)

- You need a quick one-off stimulus → `forced-connections`.
- The problem needs mechanism transfer with stated limits now → `analogical-thinking`.
- The situation is messy with no shared picture → `rich-picture-catwoe`.

## Process

1. **Intake — name the familiar to estrange.** State the problem, whose problem it is, and the metaphor everyone already uses (if any). Mark what is observed vs. interpreted. See [references/analogies.md](references/analogies.md).

2. **Run four analogies.** In order, build personal (be the element), direct (find a parallel mechanism in another domain), symbolic (compress the problem into a paradoxical phrase), and fantasy (wishful, constraint-free). See [references/analogies.md](references/analogies.md) and [scripts/synectics.py](scripts/synectics.py).

3. **Excursion — depart fully.** Choose the most evocative analogy and explore it as a world of its own for 5–10 minutes, with no attempt to solve the original problem. Record the excursion as a separate page. See [references/excursion.md](references/excursion.md).

4. **Force the return — make the strange familiar.** Map the excursion world back onto the original problem: what structure, rule, or relation in the excursion could govern the problem? Record the forced fit as a candidate concept.

5. **Generate springboards.** For each forced fit, write springboard ideas — partial, mechanism-flavored possibilities — without judging. See [references/springboards.md](references/springboards.md).

6. **Harvest and decide next.** Select 2–3 springboards with a testable mechanism; define the smallest probe and the owner. See [references/examples.md](references/examples.md).

## Rules

- Four analogies in order — do not skip to direct or fantasy prematurely; each type estranges differently.
- Excursion stays separate from forcing — departure and return are distinct pages; blending them collapses the method.
- Personal analogy requires embodiment language: "I am …" — not "it is like …".
- Symbolic analogy must be a compressed paradox ("trusted stranger," "silent signal"), not a slogan.
- Record what happened before interpreting why — observation before insight.
- Label fact / assumption / speculation; excursion contents are not evidence.
- Honest provenance: attribute Synectics to Gordon and Prince; call this workflow an adaptation. See [references/provenance.md](references/provenance.md).
