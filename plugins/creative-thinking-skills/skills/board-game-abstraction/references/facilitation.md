# Facilitation — Timing, Solo/AI Mode, 15-Minute Playtest

## Timing (40–60 min full, 15 min playtest mandatory)

- Intake 5 min → Cast/Board 10 min → Mechanic pick 5 min → 1-page rules 10 min → Playtest ×3 15 min → Debrief 10 min.

## Solo / AI mode

- Intake via prompt; mechanic via `scripts/gameify.py --problem "..." --mechanic auto --seed 7`.
- Mental playtest: describe 3 greedy/honest/co-op runs; log divergences as assumption-tagged probes. No real players required.

## Group mode

- Coins, index cards, sticky notes as board. One scribe writes the 1-page rules verbatim.
- Playtest with 2–4 players at a table; 15 min timer is hard stop.

## Anti-drift

- Rule count ≤8; action count ≤3. More rules hides the loop.
- After playtest: read "does this rule still abstract what we claimed?" If not, label the divergence as the finding.
