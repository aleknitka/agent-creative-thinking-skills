# Options Portfolio

Do not pick one winner. Keep a small, deliberately varied portfolio — achievable, ambitious, and exploratory — so the organization learns on several fronts at once and is not locked to a single bet.

The failure mode it prevents is narrowing to the safest or the most exciting option alone while the rest of the idea set — and its information value — is lost.

## When to use

- A broad idea set needs narrowing without collapsing variety.
- One pick would hide the tradeoff between safe, ambitious, and exploratory.
- Each option needs a next experiment to earn its next stage.

If unsure this is the right method, start with [thinking-router](../thinking-router/SKILL.md) — or see [references/when-not-to-use.md](references/when-not-to-use.md).

## When NOT to use (brief)

- You need to generate more ideas → `divergent-thinking` or `brainwriting`.
- You need variations on a fixed baseline → `scamper`.
- Near commitment → `premortem`.

## Process

1. **Intake — reuse before you ask.** State the broad set, the goal it serves, hard limits, and criteria that matter for this decision. Mark fact / assumption / speculation. See [references/portfolio.md](references/portfolio.md).

2. **Score.** For each idea, score on criteria that reflect variety — feasibility, upside, learning value, and cost. Keep scores and the raw idea beside them. See [references/criteria.md](references/criteria.md).

3. **Compose the portfolio.** Select 3–5 options that together cover achievable (ships soon), ambitious (high upside if it works), and exploratory (high learning even if it fails). No two should be the same mechanism. See [references/portfolio.md](references/portfolio.md) and [scripts/portfolio.py](scripts/portfolio.py).

4. **State rationale.** For each, write why it is in the portfolio and what would make it leave. Distinct means different mechanism or bet, not different label.

5. **Define next experiments.** For each, name the cheapest probe, its signal, and the decision rule — one probe per option where possible. Keep probes small enough to run this month.

6. **Monitor and rebalance.** Name the cadence and the signal that triggers rebalancing — which option graduating, which being parked. See [references/examples.md](references/examples.md).

## Rules

- Do not pick one winner — keep a balanced mix by design.
- Variety is mechanism variety, not label variety.
- Every option has a next experiment with signal and decision rule, or it will not move.
- No option without provenance: every portfolio entry traces to a cluster in the broad set.
- Label fact / assumption / speculation.
- Honest provenance: call adaptations adaptations. See [references/provenance.md](references/provenance.md).
