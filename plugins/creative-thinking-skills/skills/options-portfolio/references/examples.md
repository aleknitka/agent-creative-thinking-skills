# Worked Example — Broad Set → 3-Option Portfolio

## Broad set (12 ideas)
Varied onboarding paths from scoping.

## Portfolio
- Achievable: short checklist on real data (ships in one sprint).
- Ambitious: pre-configured invite that skips the tour (high upside, needs intent capture).
- Exploratory: peer artifact as entry (tests social path, high learning).

Each with probe and signal.
