# Worked Example — Reminder → Attention → Activation Loop

Behavior: activation rate is flat while reminder frequency keeps rising.

## Variables and links

- Reminder frequency → attention per reminder (–, habituated).
- Attention per reminder → activation (+) .
- Activation → perceived need for reminders (–, "we fixed it").
- Activation → peer visibility (+) → activation (R, reinforcing via peers).

## Loops

- **B1 (Balancing, with delay):** More reminders || → less attention → fewer activations — balancing toward inattention, delayed because habituation lags.
- **R1 (Reinforcing):** More activation → more peer visibility → more activation — amplifies success.

## Archetype check

Matches **Shifting the Burden**: reminders (symptomatic fix) relieve pressure while undermining the fundamental solution (better first value/peer visibility). Also resembles **Limits to Growth** if capacity caps peer effects.

## Leverage and probes

- Low leverage: send more reminders (level 12, numbers).
- High leverage: make activation visible to peers (level 6, information flows) and reduce the symptomatic fix that erodes attention.

Probe: one artifact-driven activation at first open, suppressing reminders for that cohort; signal: activation without push within 24h vs. reminder cohort.

Delays marked where || appears; every link states its mechanism.
