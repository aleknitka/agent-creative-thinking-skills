# Links — Variables, Polarity, and Delays

## Variables

Variables are quantities that can increase or decrease. Name them as nouns that can go up or down ("attention paid to reminders"), not events ("reminder sent").

## Polarity

- **+ (same direction):** more of A → more of B.
- **– (opposite direction):** more of A → less of B.

Read each link as a causal sentence: "More frequency of reminders → less attention per reminder, because attention is habituated."

## Delays

Mark delays with **||** on the arrow. A delay means the effect arrives after the cause — where leverage hides and where oscillation arises. Check each link: is the effect immediate or delayed? Mark it.

## Quality check

Every link must be causal, not correlational — state the mechanism. If you cannot name the mechanism, the link is a hypothesis, not a cause.
