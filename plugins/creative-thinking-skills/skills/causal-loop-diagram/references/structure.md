# Structure — Boundary and Behavior Over Time

## Bounding the system

Name what is inside the diagram and what is taken as given. Outside the boundary are parameters; inside are variables that can go up or down. If a "cause" never changes, it is not a variable — it is a boundary condition.

## Behavior over time (reference mode)

Sketch how the key variable has behaved over the chosen horizon and how it would continue without intervention. Label the pattern: growth, decay, oscillation, or S-shaped. The diagram must explain that pattern, not just the current level.

## Starting point

After intake, the problematic behavior and its time horizon are the test for the finished CLD: does the loop structure generate that behavior?
