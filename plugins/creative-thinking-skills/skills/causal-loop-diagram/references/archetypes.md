# Archetypes — Shifting the Burden, Fixes that Fail, Limits to Growth

## Common archetypes

- **Shifting the Burden:** a symptomatic fix (more reminders) relieves pressure, undermining a fundamental solution (better first value).
- **Fixes that Fail:** a fix creates an unintended consequence that worsens the original problem after a delay.
- **Limits to Growth:** reinforcing growth hits a balancing loop (capacity, attention) that caps it.
- **Success to the Successful:** two reinforcing loops compete for a shared resource; the early winner captures more.

## How to use

Compare your loop structure to these patterns. If your diagram matches one, the leverage point is known: strengthen the fundamental solution (Shifting the Burden), remove the unintended consequence (Fixes that Fail), or expand/remove the limit (Limits to Growth).

## Checking

Name the archetype explicitly if it fits; if none fits, treat the system as novel but still label R/B and delays.

## Leverage note

Archetypes suggest leverage without prescribing it — the probe still must be testable. See the Leverage reference for leverage-point detail.
