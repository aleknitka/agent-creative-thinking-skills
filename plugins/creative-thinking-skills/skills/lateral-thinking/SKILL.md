# Lateral Thinking

Predictable answers come from dominant patterns — the "main track" your mind keeps reusing. This skill breaks that track deliberately (Po), then builds forward to usable alternatives before you optimize.

The failure mode it prevents is polishing the obvious answer while a better frame sits one sideways move away.

## When to use

- Answers feel predictable, samey, or looped ("we've tried this before").
- "We've always done it this way" / constraints feel inherited, not proven.
- You want an indirect approach before converging.

If unsure whether this is the right method, start with [thinking-router](../thinking-router/SKILL.md) — or see [references/when-not-to-use.md](references/when-not-to-use.md).

## When NOT to use (brief)

- Well-defined correctness problem (math, proof, compliance, safety-critical sequence) → use vertical / critical thinking.
- Bottleneck is missing facts → research first.
- You cannot suspend judgment right now → try `challenge-assumptions` instead.

## Process

1. **Intake — reuse before you ask.** In one sentence each: the stated problem, the real goal behind it, hard constraints, and appetite for weirdness (low / medium / high). Reuse available context; ask only what is missing.

2. **Expose the dominant idea.** Name the pattern everyone is optimizing and why it exists. Ask what is taken for granted, what boundary or continuity is assumed, and who frames the problem this way. Use [references/challenge-starter.md](references/challenge-starter.md).

3. **Generate provocations (Po).** Produce **≥5 `Po:` statements that are deliberately wrong/impossible**, using **≥3 operators** (escape / reversal / exaggeration / distortion / wishful thinking / random entry). Label each `Po:` explicitly. No judging yet. See [references/provocation-operators.md](references/provocation-operators.md) and [scripts/random_entry.py](scripts/random_entry.py).

4. **Move to usable ideas.** For the **2–3 most intriguing Pos**, apply movement — extract principle → focus on difference → moment-to-moment → positive aspects → special circumstances — to derive 1–2 practical directions per Po. See [references/movement-techniques.md](references/movement-techniques.md).

5. **Harvest alternatives.** Reframe into **3–5 distinct frames** (new "box," mechanism, assumption challenged, and one small probe/experiment each). Distinctness = mechanism or assumption challenged, not rewording. Tag every claim as **fact / assumption / speculation**. See [references/patterns-and-alternatives.md](references/patterns-and-alternatives.md) for fractionation and concept-fan options.

6. **Decide next.** Recommend whether to (a) deepen one frame, (b) combine with another method (`challenge-assumptions`, `analogical-thinking`, `scamper`, `premortem`, or Six Hats Green Hat), or (c) switch to vertical execution. Confirm with the user before running the next method. Example harvest: [references/examples.md](references/examples.md).

## Rules

- No critique during Po generation.
- Every Po must be deliberately wrong; if it sounds reasonable, make it stranger.
- Apply movement before judging — the intermediate silly idea is allowed.
- Keep variety honest: rewordings don't count.
- Visible uncertainty: label facts, assumptions, and speculation.
- Honest provenance: name the origin (de Bono); call adaptations adaptations. See [references/provenance.md](references/provenance.md).
