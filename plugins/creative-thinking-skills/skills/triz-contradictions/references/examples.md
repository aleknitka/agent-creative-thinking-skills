# Worked Example — Speed vs Accuracy

## Contradiction
If we improve speed (faster onboarding), then accuracy (correct setup) worsens, because generic fast paths skip context.

## Separation
By condition: invited users get pre-configured fast path; solo users get accurate checklist. By time: first session is fast skeleton, later refinement adds accuracy.

## Principles
Prior action (pre-configure), segmentation (different paths), feedback.
