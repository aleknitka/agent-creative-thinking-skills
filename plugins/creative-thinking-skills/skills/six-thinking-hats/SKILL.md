# Six Thinking Hats

Parallel thinking, not debate. Everyone wears the same hat at the same time so facts, feelings, caution, benefits, creativity, and process never compete in the same sentence.

These are **thinking modes, not personality types** — every participant uses every hat when it is called.

## When to use

- Brainstorming and criticism keep interrupting each other.
- A decision needs deliberate optimism *and* deliberate caution.
- The group (or you + AI) keeps mixing "what we know" with "what we feel."

If unsure this is the right method, start with [thinking-router](../thinking-router/SKILL.md) — or see [references/when-not-to-use.md](references/when-not-to-use.md).

## When NOT to use (brief)

- You need a single technical answer with stepwise correctness → use vertical thinking.
- The bottleneck is missing facts → research first, then return with the White hat.
- Time is under 5 minutes → run a single focused hat instead of the full sequence.

## Process — Blue hat runs the session

Blue manages process throughout; it opens and closes.

1. **Open with Blue — set focus.** In one sentence each: the topic/question, the real goal, what a good outcome looks like, and time available. Choose a hat sequence for that goal. See [references/sequences.md](references/sequences.md) and [references/facilitation.md](references/facilitation.md).

2. **White — information.** What do we know, what don't we know, what would we need to find out? No interpretation yet. See [references/hats.md](references/hats.md).

3. **Red — feelings and intuition.** Gut reactions, hunches, likes/dislikes — stated without justification or debate. Keep it brief and honest.

4. **Yellow — benefits and value.** Where does this work even if it is not perfect? Who benefits, under what conditions?

5. **Black — caution and risks.** What could go wrong, what is weak, what must be checked? Be specific, not dismissive.

6. **Green — creativity and alternatives.** Generate new ideas, provocations, or modifications. Use lateral moves here; quantity before quality. If stuck, pull a provocation from `lateral-thinking`.

7. **Close with Blue — synthesize and decide.** Summarize per-hat outputs, name tensions (e.g., Yellow vs. Black), and recommend next steps. See [references/examples.md](references/examples.md) for a worked trace.

For a concise summary of all six modes, see [references/hats.md](references/hats.md).

## Rules

- One hat at a time — never mix modes in the same turn.
- Every participant (including AI) uses the called hat; hats are not assigned to people.
- Do not critique during Green; do not ideate during Black.
- Time-box each hat; Blue may extend or cut short explicitly.
- Distinguish facts, assumptions, and speculation; label Red statements as subjective.
- Honest provenance: attribute the method to de Bono; call adaptations adaptations. See [references/provenance.md](references/provenance.md).
